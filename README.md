# PM / IT Project Management Platform Prototype

This is a browser-based prototype for a PM and IT project management back-office platform.

## Files

- `index.html`: main UI
- `styles.css`: page styling
- `app.js`: mock data and interactions
- `assets/screenshots`: design and verification screenshots

## Preview

Open `index.html` in a browser, or run a local static server:

```bash
python3 -m http.server 4173
```

Then visit:

```text
http://127.0.0.1:4173/
```
